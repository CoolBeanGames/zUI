# docs/

`index.html` is the zUI documentation site — a single page with a click-through
tree nav, styled with zUI itself (dogfooding). Open it directly, or serve
`docs/` from the repo root so the `../core` links resolve.

It is a hub: each section summarises a topic and points at the authoritative
markdown file (`core/PROTOCOL.md`, `core/css/THEMES.md`, `compiler/GRAMMAR.md`,
…). **When any of those change — a component, channel, token, or CLI flag —
update the matching section here too.**
