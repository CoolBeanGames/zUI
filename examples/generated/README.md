# Generated output (reference)

Sample `zslc` output for the examples in the parent folder. Regenerated by
`build.ps1`; the HTML form is produced into `builds/<config>/examples/` where the
`../core` asset paths resolve.

- `CompiledUi.g.cs` - `showcase.zsl` via the `csharp` backend
- `showcase.g.cpp`  - `showcase.zsl` via the `cpp` backend

`showcase.zsl` and `showcase.zml` compile to byte-identical output on every
backend (see `compiler/tests/test_compile.py::test_zml_equals_zsl`).
